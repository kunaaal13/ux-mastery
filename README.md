## Every concept file follows the same shape

1. **In one line** — the compressed definition.
2. **Basic** — the plain-language explanation with an everyday analogy.
3. **Deeper** — the mechanism, the boundaries, and when the idea breaks down.
4. **Applications** — concrete product examples, plus a "do this / not that" pair.
5. **Interview angle** — how the topic gets asked and how to answer it well.
6. **Check yourself** — 3–6 questions with answers at the bottom of the module quiz.

Because the shape repeats, you can skim any file for the layer you need: the one-liner before an interview, the deeper section when you are actually designing.

## Suggested pace

- **Fast track (2 weeks):** Modules 01, 03, 05, 09, 12 + all of `interview-prep/`.
- **Standard (6 weeks):** One module every 2–3 days, one exercise per module, one mock interview per week.
- **Deep (3 months):** Every module, every quiz, every exercise, plus the books in `resources/books.md`.
