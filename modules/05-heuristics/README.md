# Module 05 — Heuristics & Evaluation

**Goal:** be able to pick up any interface and produce a structured, prioritised list of problems in 20 minutes — with severity ratings and fixes. This is the single most directly testable UX skill, and it is an entire interview round at many companies ("app critique").

| File | Concept |
| --- | --- |
| `5.1-nielsen-heuristics.md` | The 10 usability heuristics, each with violations and fixes |
| `5.2-other-heuristic-sets.md` | Shneiderman's 8 Golden Rules, Tognazzini's principles, when to use which |
| `5.3-running-an-evaluation.md` | Heuristic evaluation method, severity scales, cognitive walkthrough, expert review, reporting |
| `quiz.md` | 14 questions with worked solutions |

**Interview payoff:** `interview-prep/question-bank/app-critique.md` is built directly on this module.
