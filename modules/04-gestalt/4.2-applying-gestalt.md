# 4.2 Applying Gestalt — Spacing, Alignment, Diagnosis

## In one line

Gestalt becomes practical through two systems: a spacing scale that encodes grouping, and an alignment grid that encodes continuity.

## Spacing as meaning

Spacing is not decoration; it is the primary carrier of structure. A usable convention:

```
4  — inside a component (icon to its label)
8  — tightly related elements (label to input)
16 — related elements within a group (field to next field)
24 — between groups within a section
40 — between sections
64 — between major page regions
```

The exact numbers matter less than the **ratio discipline**: adjacent levels should be clearly distinguishable, and you should be able to state, for any two elements, which level of relatedness their gap encodes. Using a 4- or 8-point scale keeps this decidable and makes handoff unambiguous.

**The single most common layout bug:** the gap *between* groups is equal to or smaller than the gap *within* them. The eye then groups by something else — usually by row — and the intended structure is invisible.

## Alignment as continuity

- Pick a small number of alignment edges per screen and hold them. Every new left edge is a new implied line, and each one weakens the others.
- Text alignment: left-align body text in left-to-right languages; centred text is acceptable for short headlines only, because centring destroys the shared left edge that lets the eye return to the next line.
- Optical alignment beats mathematical alignment for glyphs and icons. Round shapes need to overshoot slightly to *look* aligned.

## The squint test

Blur or squint at your design. What you still perceive is what users perceive in the first 200 ms:

1. **Do the right things group?** If not, spacing or region boundaries are wrong.
2. **Is there a clear first stop for the eye?** If everything is grey mush, you have no hierarchy.
3. **Does the primary action still stand out?** If not, Von Restorff has been spent on too many elements.
4. **Can you tell figure from ground?**

Ways to run it: squint, blur the screenshot, view it at 25% zoom, or convert to greyscale — the last one also checks that you are not relying on colour alone.

## Diagnosing common layout complaints

| Complaint | Likely Gestalt cause | Fix |
| --- | --- | --- |
| "Cluttered" | Uniform spacing, no grouping signal | Introduce a spacing scale; increase between-group gaps |
| "Disorganised" | Too many alignment edges | Reduce to 2–3 edges; enforce a grid |
| "I cannot find the button" | No figure/ground or isolation | One filled primary; reduce competing weights |
| "Which label goes with which field?" | Proximity violation | Label closer to its own field than to the previous one |
| "These two things look the same but do different things" | Similarity misapplied | Differentiate visually; behaviour and appearance must agree |
| "The modal feels unattached" | Weak figure/ground | Stronger scrim, elevation, or a clear anchor |
| "The sections run together" | Between-section space ≤ within-section space | Increase section spacing, or add common region |
| "It feels heavy" | Too many boundaries | Replace borders with white space; use region only where it earns its place |

## Borders vs. space

New designers reach for borders; borders add visual weight and multiply the lines the eye must parse. Prefer, in order:

1. **Space** — free, adds no weight
2. **Background tint** — common region without hard edges
3. **A single hairline** — when space is genuinely unavailable
4. **A full border with radius and shadow** — when the group must be portable (a card) or interactive as a unit

## Density is a decision, not a default

Consumer products lean spacious (low density, high clarity, fewer items per screen). Professional tools lean dense, because expert users trade comfort for the ability to see more state at once — a trading terminal with consumer spacing is unusable. Match density to **frequency of use and expertise**, and provide a density toggle when both audiences exist.

## Interview angle

**Common questions**
- "How do you approach spacing in a design?"
- "Redesign this cluttered screen — talk me through it."
- "How do you decide between using a card and using white space?"

**Answer for the card question** — "Common region overrides proximity, so a card is the strongest grouping tool I have short of a connector. I use it when the group must be scannable in a repeating set, when it needs its own interactive target, or when the surrounding density makes spacing unreliable. I avoid it when it is one of many nested containers, because every boundary adds weight and boxes-in-boxes flatten hierarchy. My default is space first, tint second, card last."

**When asked to redesign live**, narrate in this order: primary task → grouping → hierarchy → spacing scale → emphasis → states. Do not start with colour. Interviewers are listening for whether structure precedes surface in your thinking.
