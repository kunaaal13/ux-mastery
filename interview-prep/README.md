## The typical loop

| Round | Length | What is tested |
| --- | --- | --- |
| Recruiter screen | 30 min | Fit, level, salary range, communication |
| Hiring-manager screen | 45 min | Process, scope of past work, collaboration |
| Portfolio presentation | 45–60 min | Depth, decisions, impact, storytelling |
| App critique | 45 min | Craft vocabulary, judgement, structure |
| Whiteboard / design challenge | 45–60 min | Problem framing, ideation, communication under pressure |
| Cross-functional (PM / eng) | 45 min | Collaboration, trade-offs, pragmatism |
| Take-home | 4–8 hrs claimed | Everything, plus scoping judgement |

Ask the recruiter for the exact loop — it is a normal question and it tells you what to rehearse.

## The four failure modes

1. **Narrating what you made instead of why.** Screens without decisions read as decoration.
2. **No numbers.** Not necessarily revenue — task success, support tickets, adoption, time saved. Any measured outcome beats none.
3. **No trade-offs.** Any answer that treats a principle as free reads as junior.
4. **Not answering the question asked.** Rehearsed stories delivered regardless of the prompt.

## How to use this section

- Read `frameworks/` first; they are the skeletons every answer hangs on.
- Answer out loud, timed, recorded. Watching yourself back is unpleasant and the fastest available improvement.
- Drill concepts with [`quizzes/flashcards.md`](../quizzes/flashcards.md) and the module quizzes before rehearsing delivery.
