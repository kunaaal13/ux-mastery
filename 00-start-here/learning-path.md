# Learning Paths

Pick the path matching your situation. Each path lists modules in dependency order, not repo order.

## Path A — Complete beginner (no design background)

You need vocabulary and a mental model of the process before anything else.

1. `01-foundations` — what UX is, the double diamond, roles
2. `04-gestalt` — the most immediately visible principles; you will start seeing them everywhere
3. `03-ux-laws` — Fitts, Hick, Miller, Jakob first; the rest after
4. `06-visual-design` — hierarchy and spacing carry more weight than colour
5. `05-heuristics` — now you can critique
6. `07-interaction-design` — states, feedback, affordances
7. `02-psychology` — the *why* under laws 03 and 04
8. `08` → `09` → `10` → `11` → `12` → `13`

**Milestone:** after step 5, you should be able to critique any app screen for 5 minutes without running out of things to say.

## Path B — Developer moving into UX / design engineering

You already know component thinking; you need the human side.

1. `05-heuristics` — gives you a critique checklist immediately
2. `10-accessibility` — you can act on this in code today
3. `11-design-systems` — closest to your existing mental model
4. `03-ux-laws` + `04-gestalt` — the rules behind the design decisions you have been implementing
5. `06-visual-design` — the part developers most often skip and most often need
6. `09-research` — the biggest gap for most engineers
7. `02`, `07`, `08`, `12`, `13`

**Milestone:** you can explain a design decision without saying "the designer asked for it."

## Path C — Interview in under 2 weeks

Depth is a luxury; coverage and delivery win.

- **Days 1–2:** `01-foundations`, `05-heuristics` — you need the process narrative and the critique checklist.
- **Day 3:** `03-ux-laws` — memorise 8 laws with one application each.
- **Day 4:** `09-research` — methods, when to use which, sample sizes.
- **Day 5:** `12-metrics-strategy` — HEART, north-star metrics, A/B basics. This is where most candidates are weakest and where senior signal comes from.
- **Day 6:** `10-accessibility` — WCAG levels, POUR, contrast ratios.
- **Days 7–8:** `interview-prep/frameworks/` — memorise CIRCLES and STAR, then rewrite your two strongest projects into the case-study structure.
- **Days 9–11:** `interview-prep/mock-interviews/` — one per day, timed, spoken aloud, recorded.
- **Days 12–13:** `interview-prep/question-bank/behavioral.md` — write 8 STAR stories covering conflict, failure, ambiguity, influence, data, craft, speed, and collaboration.
- **Day 14:** portfolio walkthrough rehearsal + questions to ask the interviewer.

## Path D — Levelling up from junior to senior

The gap is rarely craft. It is judgement, scope, and influence.

1. `12-metrics-strategy` — connect design to business outcomes
2. `09-research` — own the discovery phase, not just the deliverable
3. `13-advanced` — ethics, behavioural design, trade-off reasoning
4. `11-design-systems` — designing for other designers
5. `05-heuristics` — but this time as a facilitator running evaluations with others
6. Re-read `03-ux-laws` looking specifically for the **counter-cases** noted in each file

**Milestone:** you can say "we chose the worse-looking option because it moved the activation metric, and here is how we validated that."
